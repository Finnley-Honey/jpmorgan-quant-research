# JP Morgan Quantitative Research Virtual Experience

This repository contains my solutions to the JP Morgan Quantitative Research Virtual Experience Programme, demonstrating quantitative modelling techniques for commodity pricing, financial contracts, and credit risk analysis using Python.

## Project Overview

The programme focused on applying Python and quantitative methods to solve practical problems encountered in financial markets and risk management.

## Tasks Completed

### 1. Commodity Price Forecasting

- Explored historical natural gas price data.
- Engineered cyclical time features (sine and cosine month encoding) to capture seasonal patterns.
- Trained a linear regression model to estimate natural gas prices for arbitrary future dates.

### 2. Natural Gas Storage Contract Valuation
- Implemented a natural gas storage contract valuation model.
- Accounted for injection and withdrawal dates.
- Included storage capacity, injection/withdrawal rate limits, storage costs, and transportation costs.

### 3. Credit Risk Modelling
- Built a logistic regression model to estimate borrower default probability.
- Evaluated model performance using a confusion matrix.
- Calculated expected loss for new borrowers using predicted default probabilities.

### 4. FICO Score Bucketing
- Developed an algorithm to partition continuous FICO scores into discrete credit risk buckets.
- Assigned internal borrower ratings based on optimised score intervals.
- Calculated expected loss using borrower risk categories.
